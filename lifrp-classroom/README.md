# 李方玲的化学课：雨前最后一题

LiFrP Classroom：TypeScript + Vite + Three.js 的校园解谜游戏。故事中的异常事件均为虚构演出；上传照片仅作为学校布局与材质参考，不随网站公开。

> 本文件包含完整机制、通关步骤和结局剧透。攻略只保留在 GitHub，不复制到游戏站点。

## 环境与运行

- Node.js 18.19 或更高版本；依赖由 `package-lock.json` 锁定。
- 现代支持 **WebGL 2** 的浏览器。WebGL 是浏览器图形接口，不是玩家需要单独安装的软件。
- 浏览器应开启硬件加速。不支持 WebGL 2 时会明确提示，不能把回退文字页当成完整 3D 游戏。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run assets:validate
npm run build
npm run preview
```

生成的 `dist/` 可部署到 GitHub Pages 仓库站点。资源使用 Vite 相对路径，不写死 `/assets`；完整 Three.js 只在进入课堂时加载。

### 重做资产

已生成的 GLB 随项目提供，普通运行和部署不需要 Blender。修改几何与材质时：

```sh
# Ubuntu 容器内的资产生产/验收工具
sudo apt-get install blender mesa-utils xvfb libgl1-mesa-dri
npm run assets:refine
npm run assets:optimize
npm run assets:validate
```

`assets:refine` 用 Blender 导入原始模块、修边、调整材质、添加校园细节，并按材质及剖切区域合并网格；`assets:optimize` 用 glTF Transform 清理、去重、焊接和 Meshopt 压缩，输出桌面/移动两个层次，保留 Y-up 米制尺度。Khronos glTF Validator 检查错误，解码后再次检查材质与几何。清单在 `public/assets/models/manifest.json`。

### 验收命令

先构建再验收；完整流程测试会自行启动带 `/LFL/` 子路径的生产服务器：

```sh
npm run build
npm run qa:production
# 帧率前后对比需另开 npm run dev
npm run qa:performance
```

`QA_URL` 可指定生产预览或线上 URL，`QA_OUTPUT` 可指定证据目录（默认 `/tmp/lifrp-qa-v2`）。性能前后对比需要开发服务的 `?assetBaseline=1`；仅验收生产包时设置 `NO_BASELINE=1`。

Linux 容器使用 Xvfb + Chromium + ANGLE + Mesa llvmpipe 验证真实 WebGL 2。这里的 FPS 是**软件渲染的同环境测量**，不能宣称等于手机真机 GPU 帧率。QA 必须观察模型成功加载、实际绘制帧、绘制调用和三角形数，不以“有 canvas/没有报错”代替 3D 成功。

## 开局与存档

1. 填写姓名，只用于称呼、本机存档，不上传网络。
2. 选择前三排或后三排，再选择班级身份。
3. 点击“开始新游戏”，抽取一次隐藏难度，整个存档保持该难度。
4. 确认具体座位。
5. 三种模式的存档各自独立。菜单明确区分新游戏与继续存档，不再用姓名是否为空判断是否续玩。

新版采用独立的 v2 本地存档键，旧原型存档不删除、不冒险转换成新状态。清理浏览器数据会删除本机进度；没有服务器云存档。每次行动、章节结算和游玩期间定期保存，离页也尝试保存。

## 座位和身份

### 前三排

随机分配具体座位；确认前可以保留原位，或换到左右相邻位置，调整最多一次。

### 后三排

候选数：简单 2、普通 3、困难 4、恐怖 5。只展示候选名字，不提前描述隐藏效果。

- **LZY**：较强的老师视线与点名压力，偷吃的巡视窗口更苛刻。
- **WYH**：较强异常与心理压力；追逐限时更紧。
- **DKH**：每局单次独立抽样，出现概率固定 1%，最多一个。免疫负面状态、截止时间惩罚和追逐伤害，但不自动找线索、答题或完成作业。
- LZY 与 WYH 可以同时成为候选。特殊位置不会取代班级职务选择。

### 班级身份

| 身份 | 每日协作次数 | 普通难度协作概率 |
| --- | ---: | ---: |
| 班长 | 2 | 80% |
| 化学课代表 | 1 | 60% |
| 普通同学 | 1 | 40% |

协作成功短暂开放偷吃窗口；失败会暴露意图并增加状态压力。角色能力每天刷新，不因视角切换或重复点事件恢复。化学课代表也可消耗今日一次协作查阅批注登记，一次定位两道错题，但仍需自行订正。

## 操作与空间

- **桌面**：WASD/方向键移动；在画面按住拖动转向；E 交互；V 切换视角。
- **手机**：左侧真实摇杆移动，拖动画面转向，“交互”按钮调查门口；横屏优先，竖屏也支持。
- **俯视地图**：点击地面移动；天花板及遮挡墙体隐藏。门口金色标记与第一人称使用相同坐标。
- **第一人称**：真实房间模型、碰撞边界和桌椅障碍。接近门口后 E/交互进入相邻房间。
- 普通调查阶段也提供房间节点选择，方便移动端查看不同地点的证据；追逐期间关闭快捷房间跳转，必须实际走到门口。
- “事件”按钮收起/展开解谜面板；“记录”查看已发现线索与台词。
- 设置期间暂停游戏；网页隐藏时停止渲染循环，返回前台继续。
- 全屏需要浏览器许可；不支持原生全屏的浏览器会提示，不影响横屏游玩。

## 难度与时间

难度名称不显示在游戏 HUD；新游戏概率为简单 10%、普通 30%、困难 40%、恐怖 20%。

| 难度 | 行动时间倍率 | 老师注意/状态倍率 | 切视角停顿 | 偷吃目标 | 耳语次数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 简单 | 1.35 | 0.75 | 1 秒 | 2 | 5 |
| 普通 | 1 | 1 | 1.5 秒 | 3 | 4 |
| 困难 | 0.8 | 1.25 | 2 秒 | 4 | 3 |
| 恐怖 | 0.6 | 1.5 | 3 秒 | 5 | 2 |

协作和注意力转移概率以普通为基准，简单 +10、困难 −10、恐怖 −20 个百分点，并限制在 0–100%。DKH 的稀有概率固定；研究性问题的 5%/50%/65% 按单独确认的机制处理。

切换视角期间不能移动，计时和危险继续。事件倒计时随状态保存；切目标、刷新和续局不重新抽难度，也不恢复已经用掉的时间。

怀疑/心理压力内部各为 0–100；游戏只显示平稳（0–24）、注意（25–49）、紧张（50–74）、危险（75–99）。任一达到 100 立即结束；完成度用目标进度描述，不能把完成 100% 当作失败。

## 三种模式与主线

- **一天生存**：从已解锁内容取最多三项；全部得到结果后结算。
- **多天章节**：初始开放第 1 章；一章内所有任务处理完可继续下一天，单项失败不会把主线永久卡住。
- **随机挑战**：完成第 1 章后开放；开局从已解锁池抽最多四项并固定顺序，刷新 UI 不会重抽。

主线顺序：
1. 订正作业、上课偷吃。
2. 研究性问题、未讲过知识点。
3. 抄作业怀疑、奶茶。
4. 求雨占体育课。
5. 三日假期巨量作业。

主线推进开放对应事件池；完成全部五章后可在挑战模式重玩。每个模式保留自己的一局进度，主线解锁进度另外保存。

## 八项事件通关教程

### 1. 课前订正作业

教室中检查第二题红笔批注和末页第五题红圈，不能只翻两次页就算完成。

- 第二题：CO₂ 的相对分子质量，`12 + 16 × 2 = 44`。
- 第五题：配平为 `2H₂ + O₂ → 2H₂O`。
- 两题都选好后提交。错误订正或超时触发对应难度后果。

### 2. 上课偷吃

观察事件面板里的实时巡视/板书窗口；老师看向这里时不要吃。板书阶段吃一口后等待咽下冷却，再继续，直至达到本局目标。协作成功可打开额外安全窗口，但次数有限；协作结果不能通过刷新重抽。

### 3. 后三排研究性问题

先读板书中的控制条件，再查粉末与块状碳酸钙实验记录。

正确推理：等质量样品分别与相同且足量的酸反应，粉末接触面积更大，所以反应更快；最终产气总量相同。不要选择“颗粒更多所以总气量更多”或“粉碎产生催化剂”。

- 耳语每次 5% 听清，50% 会被叫停；它只是辅助，自己取证也能解题。
- 回答每次 65% 可能没被老师听清，需要重复；这种情况**不扣答错机会**。
- 老师听清并判断正确才成功；被听清的错误答案达到两次才失败。

### 4. 礼貌说明知识点没讲过

教室核对板书、课本；走廊找同学核对笔记。收齐三项证据，回教室依次完成三轮表达：
1. 说明已经核对过的事实。
2. 请求对应页码或补充解释。
3. 表达愿意补学、独立完成订正。

不能越过证据阶段直接判定成功。

### 5. 防止被怀疑抄作业

教室保留有计算顺序的草稿，走廊询问证人，回教室解释守恒列式与单位验算，再比较两人**正确解答中的推理差异**，提交四项证据。

结论一样不自动代表抄袭；故意把答案改错不算证据。重复收集同一项不增加证据数。

### 6. 避免请奶茶

走廊询问她说“受着”时的语气，办公室核对订单和付款便条，再回走廊判断真实意图。

判断确实要付款后，用待签材料转移注意力。成功可直接化解；失败先进入绕行阶段，**不是立刻判定整个事件失败**。启动绕行后，实际走到办公室门口，按交互进入安全房间，才算脱身。

### 7. 阻止求雨占体育课

三项证据缺一不可：教室课表/便条、办公室未批准的记录、走廊同学证词。集齐后，任选一条即可成功：
- 走廊：出示证据协商撤回。
- 教室：依据记录撤下未批准道具。
- 办公室：提交完整材料组织介入。

不需要三条路线全做，也不能只拿一项证据就成功。

### 8. 三日假期化学作业

每天四个时段，共三天；先选择劳逸结合或集中做题。
- **追踪**：花一时段找到下一组缺页，不算做完。
- **做题**：花一时段完成一组已找到的题。
- **休息**：劳逸结合模式下，每天最多一次，花一时段降低压力。
- 提前结束当天会放弃剩余时段；进入次日需重新排程。

推荐安排：第一天找/做/找/做，第二天同样四步，第三天休息/找/做，然后提交。需要找到五组且实际完成五组，不能只收集或无限休息刷通关。

## 失败、追逐与结局

简单事件失败可继续；普通增加怀疑/压力；困难或恐怖会按事件触发追逐。追逐时镜头转为第一人称，门口标记可引导路线；先离开老师附近，沿通道抵达指定安全房间。被追上或限时结束才产生追逐失败，不是进入追逐就自动判恐怖结局。DKH 不受到这些负面后果。

- **完美结局**：所有目标成功，沿途各阶段怀疑与压力均处于低档。
- **普通成功**：完成这段经历并安全离开，但有失误或较高压力记录。
- **坏结局**：怀疑/压力达 100 立即失败；终局结算时任一状态处于危险档（75–99）也进入坏结局；困难追逐失败同样如此。
- **恐怖结局**：恐怖难度追逐失败。

## 声音、画质和性能

- 合成语音默认关闭，可统一开关；角色选择系统中文声线，缺少多声线时使用语速/音高区别。浏览器语音不是预制专业配音，不保证不同系统听感一致。
- 环境底噪与事件音效由 Web Audio 实时合成，无需外部音频请求；首次交互后解锁。
- 自动画质：触控设备选移动标准，桌面选高画质。低画质限制像素总量、取消实时阴影、使用移动资源。
- 运行时按房间加载，切房释放旧几何/材质/纹理；一个 RAF 循环，隐藏页面停止，设置弹窗暂停。
- 桌面静态阴影按需更新；移动不使用实时阴影。模型按材质与剖切组批量合并，地图视角隐藏天花/遮挡墙体。
- `window.__lifrp.metrics()` 是只读诊断信息，包含实际渲染帧、帧时间、绘制调用、加载耗时等；它不是修改游戏的作弊接口。

### 本地性能记录（2026-10-06）

使用同一个 Chromium / Mesa llvmpipe 软件渲染环境，960×600、中画质、无实时阴影，预热后采样约 6.5 秒：

| 教室资源 | 绘制调用/帧 | 平均 FPS | 平均帧时间 | 文件大小 |
| --- | ---: | ---: | ---: | ---: |
| 原始模型（先修复 WebGL 初始化） | 515 | 31.07 | 32.18 ms | 300,200 B |
| 精修移动模型 | 20 | 32.45 | 30.82 ms | 211,060 B |

绘制调用减少约 96.1%，移动模型比原文件小约 29.7%，且增加了修边、道具和三张内嵌纹理；同条件软件帧率提升约 4.4%，不是数倍提升。844×390 移动标准档测得 35.45 FPS。桌面高档在纯软件渲染器仅约 9.54 FPS，不能据此推断真实 GPU；自动档会在持续慢帧时逐步降档，也可手动选低档。

原已发布版本因 WebGL 1 探测占用画布而没有成功初始化 WebGL 2，无法给出有意义的原版帧率。因此此表比较的是**修好初始化后的原始资源**与精修资源，不是声称从原上线版测出了帧率。
