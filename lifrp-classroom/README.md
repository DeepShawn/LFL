# 李方玲的化学课：雨前最后一题

LiFrP Classroom 是一个基于 Three.js 和学校 GLB 场景的哥特校园解谜游戏。你会在同一局里切换斜俯视地图与第一人称探索视角，在教室、走廊和办公室的节点之间处理课堂、作业和假期事件。

> 这是完整攻略，包含剧透。想先体验游戏，请直接运行 `npm run dev`，不要先读后面的结局部分。

## 运行

```bash
npm install
npm run dev
```

生产构建与检查：

```bash
npm run typecheck
npm test
npm run assets:validate
npm run build
```

GitHub Pages 使用相对资源路径，生产文件在 `dist/`。

## 开局

1. 输入姓名。姓名只影响称呼、开局介绍和本地存档显示。
2. 先选前三排或后三排。
3. 选择班长、化学课代表或普通同学。
4. 点击进入课堂。
5. 每次新游戏会隐藏随机一种难度，不显示难度名称。
6. 进入后三排时，系统按难度生成候选座位，玩家只看到位置名称，不会提前看到效果。

### 座位

- **前三排**：系统随机分配具体座位，确认前可以从左右相邻座位中调整一次。
- **后三排**：候选数量由难度决定：简单 2 个、普通 3 个、困难 4 个、恐怖 5 个。
- **LZY**：主要提高课堂点名与老师视线压力。
- **WYH**：主要提高异常事件和附近区域影响。
- **DKH**：独立按 1% 概率出现，最多一个；对点名、怀疑、追逐、惊吓、作业惩罚等所有负面效果完全免疫，但不会自动完成目标。

### 身份

- **班长**：每天可组织 2 次课堂干扰。
- **化学课代表**：每天可协作 1 次，作业/实验线索更容易找到。
- **普通同学**：每天可协作 1 次，但协作成功率最低。

协作的普通难度基础成功率依次为 80% / 60% / 40%。简单难度加 10 个百分点，困难难度减 10 个百分点，恐怖难度减 20 个百分点。协作本身会增加少量怀疑度。

## 操作

- **桌面**：WASD 或方向键移动；按住鼠标拖动转向；E 互动；V 切换 2D/3D。
- **手机**：横屏优先；使用虚拟移动按钮、视角按钮和调查按钮。页面同时支持竖屏和全屏按钮。
- **2D 视角**：斜俯视地图，可点击发光标记调查黑板、作业本、办公室和走廊线索。
- **3D 视角**：第一人称探索，使用学校 GLB 场景。
- **切换代价**：简单 1 秒、普通 1.5 秒、困难 2 秒、恐怖 3 秒；切换期间不能移动且时间继续。
- **配音**：设置中开启浏览器中文合成语音；默认关闭，文字台词始终可用。

## 难度

隐藏难度概率为：简单 10%、普通 30%、困难 40%、恐怖 20%。

| 难度 | 时间倍率 | 老师注意 | 怀疑/压力 | 研究提示 | 失败后果 |
| --- | ---: | ---: | ---: | ---: | --- |
| 简单 | ×1.35 | ×0.75 | ×0.75 | 5 次 | 标记事件失败但继续 |
| 普通 | ×1 | ×1 | ×1 | 4 次 | 增加怀疑与压力 |
| 困难 | ×0.80 | ×1.25 | ×1.25 | 3 次 | 异常或短追逐 |
| 恐怖 | ×0.60 | ×1.50 | ×1.50 | 2 次 | 强制追逐或高压场景 |

怀疑度和心理压力内部为 0–100。HUD 不显示具体数值，只显示四档：平稳（0–24）、注意（25–49）、紧张（50–74）、危险（75–99）。任一达到 100 会立即失败。

## 三种模式

- **一天生存**：在已解锁事件中处理最多 3 项，一天结束时结算。
- **多天章节**：主线五章、多节点推进；第 1 章从订正作业和偷吃开始，最终进入假期作业终章。
- **随机挑战**：完成第 1 章后开放，从当前已解锁事件池抽取最多 4 项。

三种模式各自自动存档。事件节点、每天结束和章节结算都会保存到浏览器本地存储。

## 八项事件攻略

### 1. 课前订正作业

在作业本里先翻查红笔批注，再检查最后一页被圈出的研究题。找到两组错题线索后点击完成订正。没有找全就交出，作业会被扣下。化学课代表在相关线索上更有优势。

### 2. 上课偷吃

每次新游戏需要完成：简单 2 份、普通 3 份、困难 4 份、恐怖 5 份。核心是点击“寻找视线空档”，不是连续点击。需要干扰时，班长、课代表和普通同学按各自次数与难度修正提供帮助；协作会增加少量怀疑度。

### 3. 后三排研究性问题

- 提示次数：简单 5、普通 4、困难 3、恐怖 2。
- 每次小声提示只有 5% 概率听清。
- 每次提示有 50% 概率被李方玲叫停并要求同学转身。
- 玩家回答有 65% 概率被老师听不清，需要重复。
- 如果老师听清但答案错误，最多允许两次回答。
- “结合线索推理”可以在没听清时依靠课堂证据作答。

### 4. 没讲过的知识点

先查看三类证据：板书没有该式子、课本页码对不上、同学也没有听过。之后进行多轮表达：先说明事实，再请求指出页码或澄清，最后表达愿意学习。只说“没讲过”而不完成礼貌结构会增加心理压力。

### 5. 防止被怀疑抄作业

完整证据链必须包含：

1. 保留自己的解题痕迹。
2. 准备前后一致的解释。
3. 获得同学证词支持。
4. 检查关键答案不能完全一致。

四项都完成后，该事件成功。

### 6. 避免请奶茶

先询问同学和观察李方玲的言行，判断她是否真的要求你请奶茶。她可能直接说“受着”。确认后先点击转移注意力；转移成功即可直接化解。转移失败再沿走廊和办公室路线躲避。

### 7. 阻止求雨占体育课

调查必须覆盖三类证据：

- 教室的天气、板书和异常物品。
- 办公室里的记录、材料或异常布置。
- 同学的耳语与证词。

阻止方式有三条替代路线，任意一条成功即可：对话阻止、物品干预、组织介入。简单难度失败后继续；普通增加状态；困难出现异常或短追逐；恐怖进入强制追逐/高压雨夜。

### 8. 假期巨量化学作业

追踪 5 组题目线索，分别处理缺页、批注和隐藏题目。可以点击完成一组题，也可以休息降低心理压力。全部线索完成且压力没有达到 100，点击提交整份作业才成功。

## 结局

- **完美结局**：章节目标全部完成，怀疑度和心理压力都处于平稳或注意。
- **普通成功**：安全离开，但存在事件失误或状态偏高。
- **坏结局**：怀疑度或压力达到危险并导致目标失败，或未能安全处理当天事件。
- **恐怖结局**：恐怖难度进入异常/追逐路线后失败。

## 资源说明

`public/assets/models/source/` 保留附件中的原始 GLB。`public/assets/models/optimized/` 是当前网页运行版本；由于容器没有 Blender 或 glTF Transform，本版使用原始低模作为几何基线，叠加 Three.js 材质粗糙度、灯光、雾效、阴影、交互标记和移动端像素比控制。没有把未经验证的几何重建描述成已完成。

模型包包含：

- `classroom.glb`
- `corridor.glb`
- `office.glb`
- `exterior_block.glb`
- `school_scene.glb`
- `school_collision.glb`
