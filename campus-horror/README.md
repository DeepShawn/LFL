# 附中夜录：最后一遍点名

> 广播叫到你的名字时，先确认它念的是哪一行。

一款可部署到 **GitHub Pages** 的中文校园恐怖网页游戏，融合规则怪谈、中式灵异、探索解谜与潜行追逐。成年校友林舟收到旧物领取通知，再次走进校园时，时间停在了22:17，而点名册上多出了一行。

**本作为原创虚构故事。** 校园空间关系参考用户提供的武汉大学附属中学示意图；室内布局、人物、仪式与超自然事件均为原创，不代表真实学校的历史、现状或官方立场。

## 游戏内容

- 五栋楼主线：行政楼 → 实验楼 → 教学楼 → 宿舍 → 食堂，包含返程调查和三个结局。
- **第一人称3D / 2D俯视自由切换**：室内、室外和追逐中均可切换；共用位置、敌人、背包、SAN和剧情，不会借切换清除危险。
- **物件点击解谜**：建筑木牌、电路开关、座位核验、旧纸拼合和归名仪式。
- **互动文字**：调查、核验、回应与关键选择影响遭遇和结局。
- **SAN生存系统**：低SAN加深暗角、收紧视野并增加声音干扰；提供三种恢复方式。
- 独立的新手教程，以及完整的简单、困难模式，各自保存进度。
- 自动存档、检查点重试、键鼠操作和手机触控。
- 运行资源随包提供，不依赖运行时CDN、账号、数据库或后端接口。

## 部署到 GitHub Pages

### 使用部署包（推荐）

1. 解压 `campus-horror-pages.zip`。
2. 将**解压后的全部内容**上传到准备发布的GitHub仓库根目录。`index.html` 必须直接位于发布目录内，不要额外包在一层文件夹中。
3. 保留所有JavaScript、CSS、`vendor/`、`README.md`及隐藏文件 `.nojekyll`；特别不要漏传本地Three.js模块与许可证。
4. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择实际上传文件的分支，发布目录选择 **`/(root)`**，保存。
6. 等待发布完成，使用Pages页面提供的站点入口访问。

**不能只上传ZIP文件，也不能只上传 `index.html`。** 发布成品不需要在GitHub上执行npm命令。

部署包结构如下，其他游戏模块也必须一并保留：

```text
仓库根目录/
├── index.html
├── README.md
├── .nojekyll
├── styles.css
├── main.js
├── game.js
├── story.js
├── interactions.js
├── modes.js
├── sanity.js
├── storage.js
├── world.js
├── renderer-3d.js
├── renderer-2d.js
├── audio.js
└── vendor/three/
    ├── three.module.js
    ├── three.core.js
    └── LICENSE
```

所有运行资源均使用相对路径，支持GitHub仓库子路径部署。不需要在代码中填写用户名、仓库名或访问令牌。

### 如果上传的是完整源码

完整源码中的网页入口在 `site/index.html`，而不是源码仓库根目录。直接选择源码仓库的 `/(root)` 并不会把 `site/` 自动变成站点首页。

建议先按下文执行 `npm run package`，再将生成的部署包解压内容发布到专用仓库或发布分支的根目录。若自行配置GitHub Actions，发布的静态目录应为 `site/`；本项目没有附带自动部署工作流。

追逐时可以切换视角，但不能借调查面板、手记或地图消除追踪；先利用墙角和遮挡脱离危险。系统暂停始终可用。

## SAN与恢复

SAN范围为0—100。70以上为清醒，40—69为不安，1—39为失衡；正式模式降至0会失败，可从最近检查点重试，不会直接锁定坏结局。

危险遭遇、持续追踪以及关闭手电后停留在异常黑暗区域会降低SAN。普通探索不会无理由持续扣值；暂停及安全调查面板中，游戏世界停止推进。

### 三种恢复方式

1. **安全灯定神**：先调查灯座并接通照明检修端口；脱离追踪后站到灯旁，停步并按住 `R` 或“定神”。可以重复使用，但有恢复上限，不能清除敌人的追踪。
2. **核验真实线索**：首次确认纸背压痕或完成相关谜题时恢复少量SAN。同一条证据不能反复领取奖励。
3. **饮用温水**：拾取补给后按 `H` 或“温水”。数量有限，追逐中不能饮用；正式模式SAN已满时不会消耗补给。

当前简单、困难模式的参数：

| 项目 | 简单 | 困难 |
| --- | --- | --- |
| 危险SAN消耗倍率 | 1倍 | 1.5倍 |
| 灯下恢复速度 | 每秒5点 | 每秒3点 |
| 灯下恢复上限 | 80 | 60 |
| 首次线索奖励 | 10点 | 6点 |
| 每份温水恢复 | 30点 | 20点 |
| 每个温水补给点 | 2份 | 1份 |
| 敌人 | 较慢，搜索较短 | 更快，搜索更久 |

新手教程独立于正式剧情，包含移动、双视角、手电、纸背核验、SAN恢复、躲藏和检查点重试。教程SAN不会降到0；满SAN时可进行不消耗温水的饮水教学。

在“声音与显示”中可以静音、调整总音量、减弱视听特效及选择低功耗画质。**舒适设置只改变表现，不改变SAN数值与敌人规则。** 关键提示提供文字，不要求只靠听力通关。

## 自动存档与检查点

游戏使用浏览器 `localStorage`，按部署路径和游戏模式隔离记录。

- **继续游戏**：读取最近一次安全自动存档。安全状态下约每10秒保存，也会在重要安全操作后尝试保存。
- **从最近检查点重新开始**：将位置、SAN、体力、背包、补给和机关恢复到同一份完整快照；检查点之后的进度会一起回退，当前已可用的视角保留。
- 追逐、敌人搜索、敌人过近或即将触发危险时，不覆盖安全自动存档；关键遭遇前尽可能保留触发动作之前的检查点。
- 教程、简单和困难存档互不覆盖。选择已有进度的“新游戏”时，需要确认覆盖该模式。
- 存储被禁止、容量不足、记录损坏或版本不兼容时会明确提示，不假装保存成功。写入失败时，本页临时检查点不能保证在刷新后继续存在。

**这不是GitHub云存档。** 换浏览器、换设备、清除网站数据、关闭无痕会话，或改变域名、协议、端口和部署目录，都可能使原记录不可见。当前不提供跨设备同步或存档导入导出。

## 本地开发与打包

以下命令只适用于包含 `package.json`、`scripts/`、`tests/` 和 `site/` 的**完整源码目录**，不是解压后的纯网页部署包。

环境需要Node.js和npm；当前依赖要求Node.js 18以上。使用现有锁文件安装，不必安装全局构建工具。

```sh
npm ci
npm run prepare:site
npm run dev
```

预览服务默认监听4173端口，在浏览器访问本机对应端口。不要使用双击HTML的 `file://` 文件预览方式运行ES模块。

生成GitHub Pages部署包：

```sh
npm run package
```

该命令准备本地Three.js模块和许可证、检查运行资源的相对引用，并生成 `campus-horror-pages.zip`。项目根目录的README也会自动加入ZIP根目录。

## 测试

在完整源码目录执行：

```sh
npm run test:unit
npm run test:browser
```

浏览器测试需要Playwright配套的Chromium和系统运行库。若尚未下载浏览器，可执行 `npx playwright install chromium`；这会下载浏览器到本机缓存，不是部署网页的必要步骤。

在已具备Xvfb、Mesa及完整版Playwright Chromium的Linux容器中，可以使用以下软件OpenGL测试配置：

```sh
xvfb-run -a env LIBGL_ALWAYS_SOFTWARE=1 CAMPUS_MESA=1 npm run test:browser
```

这是测试环境选项，不需要访客在浏览器中配置。普通电脑先使用默认测试命令即可。

首版交付时通过31项核心测试和11组浏览器测试，覆盖两个难度的完整移动逃生路线、教程、三结局、七场景WebGL画面、SAN视听反馈、触控、存档及仓库子路径。测试截图写入 `artifacts/`，不进入部署包。尚未完成安卓真机性能和GitHub线上部署验收，后续改动仍需重新测试。

## 常见问题

**打开的是README或页面404？**  
检查发布分支和目录是否正确，`index.html` 是否直接位于发布目录。不要把完整源码中的 `site/` 当成GitHub Pages能自动识别的首页目录。

**网页空白或模块加载失败？**  
确认通过HTTP/HTTPS访问，上传了全部JavaScript、CSS和 `vendor/three/` 文件，文件名大小写未改变；开发者工具中的Network面板可检查404请求。

**没有声音？**  
浏览器通常要求用户操作后才能播放音频。点击进入游戏，或在设置中点击“启用声音”，并检查是否静音。声音不可用时仍可通过文字提示游玩。

**第一人称不可用或画面卡顿？**  
3D需要WebGL2。先尝试支持WebGL2的浏览器及低功耗画质；无法初始化时，游戏会提示由玩家明确选择仅2D继续，不会把图片当作3D。

**存档没了？**  
先确认使用原设备、原浏览器和同一站点路径。不要为了排查问题先清除网站数据，那会删除本地存档。
