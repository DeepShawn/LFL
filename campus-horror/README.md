# 附中夜录：最后一遍点名

> 广播叫到你的名字时，先确认它念的是哪一行。

中文校园恐怖网页游戏：规则怪谈、中式灵异、自由探索、纸面解谜和潜行追逐。成年校友林舟收到旧物领取通知，再次走进校园时，所有钟表停在22:17，而四十人的点名册上多出了一行。

**虚构声明：** 校园建筑的排列参考用户提供的武汉大学附属中学示意图，行政楼、实验楼、教学楼按用户说明设计为五层；室内布局、楼梯位置、角色、班级记录、仪式和异常事件均为原创架空，不是实测校园平面图，也不代表真实学校的历史、现状或官方立场。

**剧透提示：** 前六节是操作与机制说明；第七节起包含全部谜题答案、支线答案和所有结局。想自行推理的玩家可先停在第六节。

## 版本内容与游戏目标

本版的行政楼、实验楼、教学楼都包含**五层可探索空间和连续U形楼梯**，不是仅增加窗户，也不是点击菜单传送到另一层。角色和敌人拥有真实高度，上下楼会连续改变位置。

- 原五章主线仍在各楼1F完成，保留三个剧情结局。
- 三栋楼2—5F共增加12个可探索楼层：12份纸面记录、9份实物证据、3个顶层复核谜题。
- 第一人称3D、2D俯视、物件点击解谜、互动文字共同使用同一份游戏进度。
- 3D视角提供当前楼层小地图；手机可收起。
- SAN影响暗角、视野、曝光与杂音，可通过定神、温水和首次核验恢复。
- 新手教程、简单、困难为三个独立入口，存档相互隔离。
- 无战斗、无麦克风监听、无定位、无账号登录、无游戏后端。

**首次建议：新手教程 → 简单模式 → 根据手记完成主线 → 再探索五层支线。** 上层支线不是隐藏结局门槛；不必把所有楼层搜完才能离校。

本说明对应随包的五层版本。源码和发行包更新不会自动更新GitHub Pages；线上内容以实际发布的 `gh-pages` 分支为准。

## 操作与双视角

### 电脑

| 操作 | 按键或方式 |
| --- | --- |
| 移动 | `W A S D` |
| 冲刺 | 移动时按住 `Shift` |
| 转头 | 第一人称下鼠标操作；点击视野可锁定鼠标，左右方向键也能转向 |
| 切换第一人称／2D | `V` 或界面按钮 |
| 调查附近物件 | `E` 或“调查” |
| 开关手电 | `F` |
| 饮用温水 | `H` |
| 安全灯下定神 | 停步后按住 `R` |
| 手记／背包／支线进度 | `J` |
| 校园与楼层路线 | `M` |
| 暂停 | `Esc` 或“暂停”；在调查面板中可用关闭按钮返回 |
| 小地图收起／展开 | 小地图标题栏按钮 |

### 手机

- 左侧虚拟摇杆移动；第一人称下拖动主画面观察。
- 右侧按住“冲刺”，底部按钮调查、手电、温水、切视角或定神。
- 所有解谜都可以点选，不要求拖拽。碎纸也支持先选片段，再点目标槽。
- 小地图画布不拦截观察手势；收起／展开按钮可单独点击。
- 窄屏的座位、碗和碎纸槽在面板内横向滚动，不需要缩放整个网页。

### 视角之间的关系

在校园、房间和楼梯上都可按V自由切换，追逐中也允许。位置、高度、朝向、SAN、体力、敌人、背包和机关不会因切换而重置。

- 3D是第一人称透视；2D是北朝上的当前层平面视图。
- 2D不是透视外挂：不显示其他楼层的物件，不允许隔墙或隔层调查。
- 楼梯上的楼层标签按脚下高度变化，中间平台会标为楼梯间；走到南端整层平台才进入下一层房间。
- 打开可用的物件面板会暂停世界，但追踪期间不能调查或打开手记／大地图；仍可使用系统暂停。
- WebGL2不可用时会明确提示，可选择仅2D继续；不把背景图片伪装成3D。受设备限制选择仅2D时，教程的切视角项目会豁免。

### 真正上下五层的方法

三栋楼采用相同的可学习楼梯结构，每层高度差为3.6个游戏单位，没有跳跃键或电梯传送。

**上楼：**

1. 到南端东侧入口 `(28,24)`，进入楼梯间。
2. 到西侧坡道南口 `(31.5,23)`。
3. 向北走至 `(31.5,6.5)`，在过程中升至半层平台。
4. 在平台向东转到 `(36.5,6.5)`。
5. 沿东侧坡道向南走到 `(36.5,23)`，到达上一层整层平台。
6. 向西经过入口回本层房间；继续上楼则回到西侧坡道南口，再走一遍。

**下楼：**从东侧坡道南口向北走 → 半层平台向西转 → 沿西侧坡道向南走，回到下一层。重复到1F，再从南侧中部出口离开。

“西侧／东侧”始终以地图为准，不是角色转身后的左右。不要横跨护栏或走进两坡道之间的空隙；楼板、坡道与半层平台的高度不同，不能直接跨层。顶层没有通往6F的可走坡道，1F也没有地下层。

### 小地图规则

- 只在3D视角显示，北朝上；显示玩家箭头、当前楼层、附近可见的墙体、楼梯、出口和安全灯。
- 整层布局缩放到小画布，未看见的部分保持暗色；它不是全校园敌人雷达。
- 敌人、谜题答案、其他楼层物件和未取得证据不显示。
- 箭头方向跟随角色朝向；SAN和手电仍影响附近可见范围。
- 开关小地图不暂停世界，也不恢复SAN。低高度屏幕（高度不超过680像素）初始收起，可点击展开。
- `M`地图提供建筑解锁、各层用途和文字路线；它与HUD小地图不是同一个面板。

## SAN、体力与补给

### SAN显示与损失

SAN范围为0—100：

| 数值 | 状态与表现 |
| --- | --- |
| 70—100 | 清醒，曝光与声音相对稳定 |
| 40—69 | 不安，暗角与杂音增强 |
| 大于0且小于40 | 失衡，视野更紧，心跳／杂音更明显 |
| 0 | 正式模式失败，可重试检查点，不直接判定剧情结局 |

主要损失来源及当前基础参数：

- 敌人警觉、追逐或搜索期间：简单每秒1.7点，困难每秒2.55点。
- 关闭手电并停留在异常黑暗区，且不在已启用安全灯范围：简单每秒0.35点，困难每秒0.525点。
- 触发一次新遭遇：简单扣8点，困难扣12点；教程演练扣25点但最低保留15点。
- 追踪与黑暗消耗不叠加；追踪时按较高的追踪消耗计算。
- 普通探索、安全阅读、暂停和页面进入后台不会无理由持续扣SAN。教程无持续SAN消耗。

### 恢复途径

| 方式 | 简单 | 困难 | 使用限制 |
| --- | --- | --- | --- |
| 安全灯定神 | 每秒5点，上限80 | 每秒3点，上限60 | 先接“照明检修”；同层灯旁停步按住R，且未被追踪 |
| 一层新线索／首次主谜题核验 | 10点 | 6点 | 每条奖励只一次，反复阅读不叠加 |
| 每栋高层支线完成 | 10点 | 6点 | 收齐六项证据并在5F答对，只结算一次 |
| 每份温水 | 30点 | 20点 | 脱离追踪后使用，有限资源，最多恢复到100 |
| 温水补给点 | 每点2份 | 每点1份 | 每个点只能拾取一次 |

**上层纸条和实物本身只收录，不直接加SAN。** 这样不会靠反复读新楼层资料无限补血。安全灯可重复定神；SAN已经高于灯的上限时，不会被灯降低。

教程安全灯每秒恢复12点、上限100；温水每份35点、每点2份。教程SAN已满且携带温水时，饮水教学可以完成，但不消耗温水。正式模式满SAN则直接提示无需饮用。

### 体力

- 体力范围0—100，步行速度3.3，冲刺速度5.5个游戏单位／秒。
- 有移动输入且体力高于3时才能冲刺，冲刺每秒消耗21点；不冲刺时每秒恢复15点。
- 体力不足会回到步行，不造成死亡，也不直接消耗SAN。
- 温水恢复SAN，不直接补体力。低SAN特效也不改变谜题答案。

### 舒适设置

可调整音量、静音、减弱视听效果和选择低功耗画质。关闭特效不会改变SAN／敌人规则，HUD及纸面文字不会随环境一起变得不可读。所有关键声音线索有对应文字提示。

## 敌人、追逐与失败

“点名者”是架空异常形态，行为分为巡逻、警觉、追逐、搜索：

1. 遭遇开始有约2.5秒警觉预告，给玩家观察退路的时间。
2. 开手电时更容易被视线发现；熄灯会缩短检测距离，但不会让角色隐身。
3. 近距离冲刺会被听见；跨层声音与视觉需要楼梯或视线条件，楼板会阻隔视觉。
4. 丢失玩家约1.6秒后转入搜索；简单搜索约5秒，困难约9秒，重新发现则继续追逐。
5. 搜索结束返回巡逻，敌人不会因为切视角或上楼而被直接删除；存在可达楼梯时会按路径走，不瞬移追到另一层。

当前敌人基础追逐速度为简单2.4、困难3.1；巡逻速度为各自的一半。体力要留给拉开距离和绕角，不要一直对着墙冲刺。

### 遭遇触发点

| 位置／行为 | 结果 |
| --- | --- |
| 实验楼1F完成线路 | 本楼追逐教学式遭遇 |
| 教学楼1F选对17号 | 本楼完整追逐 |
| 宿舍选择打开门 | 可选遭遇，不改变结局资格 |
| 取回姓名后首次离开食堂 | 校园返程遭遇 |
| 上层首次收录4F实物，且本楼没有已激活敌人 | 高层遭遇；本楼已有敌人时不再复制一个 |
| 教程演练点 | 可重试教学遭遇 |

### 逃生原则

- 先认地形，听见字幕警告后绕墙角切断视线，再停步熄灯等待搜索结束。
- 一层或上层东北操作台附近，可沿东侧连通走廊到中央缺口，再绕到西南安全灯区域；不要正面撞向追来的敌人。
- 校园返程可向西侧绕过树池走，再向北返回行政楼；主路不是唯一可以走的位置。
- 楼梯上允许追逐与视角切换，但不能靠上下楼清仇恨。脱离追踪前不能进入另一栋楼或返回校园。
- 实际失败有两种：被点名者接近抓住、SAN耗尽。它们是游戏失败，不是第四个剧情结局。

## 自动存档与版本升级

本机浏览器 `localStorage` 保存进度，按站点目录与模式隔离。没有服务器云存档，也不把数据上传GitHub。

- **继续游戏**读取最近安全自动存档。安全状态下约每10秒保存，核验、拾取、启灯和关键节点会尽快保存。
- **检查点重试**恢复完整快照：位置、高度、楼层、SAN、体力、道具、消耗、机关、敌人与支线记录一起回退；保留当前已可用视角。
- 新楼层首次到达整层平台、启用安全灯及规定的关键进度会申请检查点，只有安全后才写入。
- 即将触发危险、警觉／追逐／搜索中、敌人过近时不覆盖安全自动存档。关键遭遇尽量保存触发之前的快照，因此重试后可能需要重做触发该遭遇的那个操作。
- 同一模式新游戏会提示覆盖；三个模式彼此不影响。
- 存储失败时如实提示。本页临时检查点不保证刷新后还在；当前页重试优先使用最新内存检查点。

### 旧版v1到五层版v2

- v1玩家／敌人原本没有高度，新版按1F、地面高度0补全，原道具和剧情标记保留。
- 若旧位置恰好在本次新增桌体／灯座碰撞里，尝试移到附近合法地面；无法安全转换就提示无法读取，保留原记录。
- 读取旧档不立即覆盖。成功写入v2之前，在同一模式键的 `:v1-backup` 后缀中保留原v1记录。
- 上层或楼梯中的v2记录会校验脚底高度与支撑表面，不把浮空／穿板坐标当成合法存档。
- 不支持任意未知版本的自动转换，也没有用户界面的导入／导出功能。

清除网站数据、换浏览器／设备、关闭无痕会话、改变域名／协议／端口／部署目录，都可能使原存档不可见。排障时不要先清空网站数据。

## 新手教程完整步骤

**以下开始包含操作答案。** 教程独立于正式校园，只有1F，不要求实际上五层，也没有剧情结局。

| 步骤 | 完成方法 |
| --- | --- |
| 1 移动 | WASD或摇杆走几步，不要只转头 |
| 2 切视角 | 按V切换一次；WebGL不支持且明确选择仅2D时此项豁免 |
| 3 手电 | 按F开关一次 |
| 4 核验纸背 | 到西北便条台 `(6,6)`，调查后点“翻到纸背 · 核验压痕” |
| 5 练习谜题 | 到东北练习台 `(22,6)`，点“翻纸确认原痕”；答案为17，完成后SAN降至55用于教学 |
| 6 定神 | 到西南安全灯 `(6,22)`，调查并接“照明检修”；关闭面板，在灯旁停步按住R，实际恢复一次SAN即可 |

## 主线逐章通关攻略

### 总流程

```text
北门读旧规
  → 行政楼1F：木牌开柜，取得原册
  → 实验楼1F：保铃保灯、断本楼播，脱离追逐
  → 教学楼1F：17号座位，脱离追逐
  → 宿舍1F：拼回旧签离联
  → 食堂1F：归名，取回姓名条
  → [可选] 食堂归还其余回声
  → 沿校园原路返程，脱离追逐
  → [真结局需要] 行政楼1F关闭重复广播总路
  → 北门：选择旧凭离校或主动认领41行
```

每栋楼入内先找西南安全灯和温水，再看西北纸条与东北操作台。纸条正面可能是误导，翻背才收录可靠说明。全部主谜题都能查看三级提示，错误预选可撤回，不消耗关键物品。

### 第一章：行政楼1F——多出来的一行

1. 到西北记录台看旧册封套，翻背核对五栋楼顺序。
2. 到东北档案台，将五块木牌依次放入：
   **行政楼 → 实验楼 → 教学楼 → 宿舍 → 食堂**。
3. 北门不属于木牌。排错可点槽位取回、撤销最后一牌或清空。
4. 点“按此顺序开柜”，取得**整本名册原件**，不是拓片。
5. 发现林舟在原册17号；红字41行没有旧压痕。实验楼入口开放。

行政广播总控虽能观察，但必须拿回姓名条后才能正式核验。现在不需要处理总控，也不必做上层支线。

### 第二章：实验楼1F——不是所有铃声都在响

1. 翻看检修记录纸背，确认柜门是“本楼分路”。
2. 东北检修柜三个开关正确状态：**铃接通、灯接通、播断开**。
3. 初始三个都接通，只需断开“播”；按“核准本楼设置”。
4. 机械校铃恢复，实体铃槌两短一长，门闩抬起。不是只听到广播录音就算通行。
5. 新遭遇开始：利用已有走廊、中央缺口和墙角脱离追踪，再从南侧出口离开。
6. 教学楼入口开放。可在安全时去 `(18,15)` 观察机械铃，关闭面板后看动画。

这里断的是实验楼支路，**不能代替终局行政楼的总路操作**。

### 第三章：教学楼1F——你的座位不在最后一排

1. 看原始座位表，以面向黑板为准：前排在上、每排从左向右八座，共五排。
2. 前两排分别为1—8、9—16；第三排第一个就是**17号**。
3. 在座位网格点**第三行第一列、17号**。
4. 网格外新添的41号椅子不是原座位，点错只提示不一致，可以重选。
5. 成功取得宿舍检索／钥匙对应的通行进度，触发追逐。先绕墙脱离，再离开。

“宿舍检索牌／柜钥匙”是完成此章后自动生效的剧情通行标记，不需要在背包里单独点击装备。

### 第四章：宿舍1F——门外的人知道你的声音

1. 翻看西北便条；在东北储物柜打开三片旧签离联。
2. 点“翻到三片纸背”，按撕口和压痕拼合：
   - 上片 **a**：第17号林舟，完整顶边，底部单齿。
   - 中片 **b**：状态已离，上单齿、下双齿。
   - 下片 **c**：22:17，上双齿、完整底边。
3. 上、中、下槽依次为 **a → b → c**；点击片段后点目标槽，或拖放；能撤回、交换和重置。
4. 按“按当前拼法核验旧联”，取得旧签离联，食堂开放。

门外声音是可选事件：隔门核验或沉默不会惩罚；**打开门会触发可重试追逐，不是坏结局**。不需要为离校再签一次到。

### 第五章：食堂1F——不属于任何人的那一碗

1. 查看归名口诀纸背：灯下置原册，门侧验旧联；册内四十碗不动，册外一碗倒扣。
2. 东北归名台中预摆：**名册原件放灯下、旧签离联放门侧**。
3. 1—40号碗都有旧刻，保持原位；检查网格外新写的**第41碗**。
4. 选择“预选倒扣第41碗”，再按“核验旧凭并归名”。
5. 取得第17号姓名条。**原册和签离联自动收回背包，不会被仪式消耗。**

你此时具备北门离校的两份必要凭证。想达成普通／坏结局可直接准备返程；想达成真结局还需完成下面两项。

### 真结局附加步骤一：归还其余回声

在食堂 `(19,7)` 的归还台，按槽序选择声条：**1、8、32**，提交“核验三份样本，归还旧应答”。这三例校准其余三十九道回声，不要求手动操作39次。

这些是被循环截留的旧应答，不是现实同学遇害或失踪的设定。关闭面板直接离开也可以，归还与否只影响真结局条件。

### 返程追逐与总控

首次在取得姓名条后离开食堂，会触发校园遭遇。可以向西绕过树池，再沿西侧向北返程；听到搜索结束提示后再进入行政楼。

真结局附加步骤二：回到**行政楼1F `(19,19)` 广播总控**，设置：

**铃接通、灯接通、重复点名总路断开**，然后按“核准总路设置”。

总控对取得姓名条的玩家开放，不要求完成三条上层支线。只断总路但未归还回声，仍不是完整散场。

### 北门最终操作

回到校园北侧 `(19,4)`，调查北门。共有凭证要求：已经取得旧签离联和姓名条。

- **“出示旧联与旧名，核验离校”**：按两项善后工作判普通或真结局。
- **“查看新签名选项”**：仅展示说明，还不会立刻判坏结局。勾选主动认领声明并点“确认：我主动认领第41行”，才完成危险选择。
- 关闭面板可以继续返回校园补做善后。凭证不齐时不会出现可完成的新签结局流程。

## 五层支线完整攻略

### 三栋楼通用规则

每条支线需要**2、3、4F各一张已翻背纸条和一份已确认实物，共六项**。只打开面板不算收录：纸条要点翻背，实物要点“检查实物痕迹并收录”。

1. 从南端楼梯上到2F，在西北收纸背、东北收实物。
2. 上3F同样收两项；需要时取本层西南温水并启灯。
3. 上4F收两项。首次确认四层实物且本楼还没有激活敌人时，关闭面板后会有高层遭遇；利用本层中央隔墙和西南区域脱离追踪。
4. 上5F，西北总结纸可读可不读，**它不计入六项取证，也不替代缺项**。
5. 东北复核台有逐项选择、撤回、重置和三级提示。缺材料时可预选但不能提交，手记列出每层缺的是纸背还是实物。
6. 答对后支线完成，简单恢复10SAN、困难6SAN，仅奖励一次。
7. 沿真实楼梯下到1F继续主线。完成与否不影响三种结局，答错不锁门、不消耗道具。

## 所有结局与获取条件

**本版本一共三个剧情结局，没有额外的第四结局。** 完成教程、被抓、SAN归零、未做支线都不单独算新结局。

共同前提：处于正式校园、可以安全调查北门，并已经完成宿舍与食堂主线，取得**旧签离联＋17号姓名条**。

| 结局 | 类型 | 准确获取条件 |
| --- | --- | --- |
| **第四十一行** | 坏结局 | 北门查看新签选项，勾选明确认领声明，再确认认领41行。优先于所有其他条件 |
| **旧名出门** | 普通结局 | 北门选择旧凭离校，但“食堂归还回声”和“行政总路停止重复播送”至少缺一项 |
| **最后一遍点名** | 真结局 | 完成归还回声、断开行政总广播，再在北门选择旧凭离校，不主动认领41行 |

### 判定优先级与全部组合

| 归还回声 | 断总路 | 最终旧凭离校 | 最终主动认领41行 |
| --- | --- | --- | --- |
| 否 | 否 | 旧名出门 | 第四十一行 |
| 是 | 否 | 旧名出门 | 第四十一行 |
| 否 | 是 | 旧名出门 | 第四十一行 |
| 是 | 是 | 最后一遍点名 | 第四十一行 |

三条高层支线不进入这张判定表。即使完成所有支线，也不会自动获得真结局；即使早期答错谜题、在宿舍开门或被抓过，仍可通过正确的最终选择达成真结局。

### 各结局最短路线

- **普通：**完成五章主线 → 不做至少一项善后 → 脱离返程追逐 → 北门旧凭离校。
- **坏：**完成五章主线 → 脱离返程追逐 → 北门查看新签选项并二次确认。不是靠SAN归零获取。
- **真：**完成五章主线 → 食堂声条按1／8／32归还 → 脱离返程追逐 → 行政1F总控保铃保灯断播 → 北门旧凭离校。

### 结局剧情摘要

- **第四十一行：**你替异常完成了它无法代签的认可。旧17号痕迹仍在，但新的41行得到了你的承认，22:17重新点名。
- **旧名出门：**你凭旧联与姓名条离开，时间走到22:18；循环还有未归册回声或未停止的播送，个人脱身但没有完整散场。
- **最后一遍点名：**其余回声归册，重复播送停止，你不补签新身份而离开；原册仍为40人，这一遍点名真正结束。

结局界面可以“重返检查点”。它恢复的是最近检查点的整份进度，不保证刚好位于最后选择之前；若准备比较结局，先理解检查点标签和善后工作的回退情况。

## 部署、更新与开发

### GitHub Pages部署包

1. 解压 `campus-horror-pages.zip`。
2. 将解压后的**全部内容**上传到发布分支根目录，使 `index.html` 直接位于根目录，不再多套一层文件夹。

5. 等待部署完成，用Pages提供的入口访问；无需GitHub服务器执行npm。

现有仓库采用 `master`保存源码、`gh-pages`根目录保存网页的分离方式。**本次本地修改与发送ZIP不自动推送远端**；要更新线上版本，需要将新版网页内容发布到 `gh-pages`。不要强制覆盖别人的分支更新。

如果上传的是完整源码，入口在 `campus-horror/site/index.html`（以工作区根目录为准）或项目内的 `site/index.html`；直接发布源码仓库根目录不会自动把它变成首页。可使用专门发布分支，或自行配置发布 `site/` 的Actions工作流。本项目没有自动发布工作流。

以下命令在含 `package.json`、`site/`、`scripts/`和`tests/`的 `campus-horror/` 目录执行；纯网页ZIP不包含npm工程。

npm ci

## 常见问题

**楼梯上不去？**

从南平台进入西侧坡道，向北到半层平台，再向东转、沿东侧坡道向南走。不要横穿护栏、空隙或贴着楼板边缘硬挤。5F没有更高的可走连接；1F没有地下层。

**为什么上层答对了，却不能去下一栋？**

上层是可选溯源。一层木牌、分路、座位、签离联、归名分别负责主线解锁，支线不会代替它们。

**5F知道答案，却不能提交？**

缺少2—4F六项记录。每层分别翻纸背、确认实物收录；仅阅读5F总结不能抵数。按J查看各层缺项。

**定神不回血？**

检查灯是否接通、角色是否停步、是否在同层灯旁且已脱离追踪；SAN若已达到该难度灯下上限，也不会继续增加。温水和新线索仍可能恢复到100。

**物件存在，但调查键灰色？**

可能离得太远、隔着墙／楼板、已经拾取、或仍被追踪。靠近可接近的一侧，等待搜索结束；桌体本身有碰撞，不要走进桌中心。

**3D物体穿墙或显示异常怎么办？**

本版将显示几何与移动碰撞对应，并移除二维中心点造成的3D整组消失；仍遇问题时请提供楼栋／楼层、操作步骤、浏览器和截图。图形上下文丢失会暂停并提示，可明确选择2D继续，恢复后再切回3D；不要在存储失败时贸然刷新。

**小地图是不是能看到所有敌人？**

不能。它不画敌人，不给跨层透视或谜题答案；完整路线说明请用M地图。

**为什么普通结局没有变成真结局？**

必须同时归还食堂回声、关闭行政总广播，并选择旧凭离校。实验楼支路不是行政总路，上层校铃调查也不是总控操作。主动认领41行会覆盖其他善后结果。

**为什么没有声音？**

浏览器可能等待用户点击。进入游戏后检查静音、总音量，或在设置点“启用声音”；关键提示也有文字。

**页面404、模块加载失败或只有README？**

检查发布分支及路径、根目录index.html、文件大小写和 `vendor/three/` 是否完整上传。不要把ZIP当成网页，也不要直接用文件预览器打开ES模块。

**存档没了／旧档报错？**

确认设备、浏览器和站点目录相同；先保留网站数据。v1只在可安全校验时升级，损坏或未知格式会明确拒绝，不会伪造成功恢复。
