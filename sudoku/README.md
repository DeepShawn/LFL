# 九格档案 · Sudoku Archive

一个纯静态 HTML5 数独游戏，包含简单、普通、高级、骨灰级四档难度，每档 100 道唯一解关卡，共 400 道题。游戏进度、笔记、用时、提示使用状态和逻辑冲突记录保存在浏览器本地。

## 本地运行

直接打开 `index.html` 即可游玩；也可以在项目根目录启动任意静态文件服务器。

```bash
npm run generate
npm run test:unit
npm run test:browser
```

`tools/generate-puzzles.mjs` 使用固定种子生成可复现题库，并在移除线索时验证唯一解。GitHub Pages 发布时，使用 `sudoku/` 目录作为站点根目录。

## 操作

- 菜单页负责选择难度和关卡，点击“开始”后进入独立棋盘页；电脑端菜单与棋盘不会同时显示。
- 点击棋盘空格，再点击数字键盘或按键盘 `1`—`9` 输入；输入只按行、列、宫检查逻辑冲突，不按标准答案判错。
- 没有选中单元格时点击数字按钮，会高亮盘面内的同一数字。
- 打开“笔记模式”后，数字按钮会在当前空白格中增删候选笔记；正式填入数字后，同一行、列、宫的对应笔记会自动清理。
- 每局有一次“使用提示”机会。提示会自动填入一个由唯一候选、隐性唯一或单位唯一空位推出的数字，并显示完整推理说明。
- 行、列或宫只剩一个空位时，填入数字后会自动补齐，并取消当前单元格选择。
- 使用方向键移动选中格，`Backspace` / `Delete` 清除；再次点击已选格可取消选择。
- “检查当前逻辑”只检查重复数字、剩余空格和可继续推出的基础逻辑，不泄露标准答案。
- 菜单页和棋盘页都可以切换白日 / 夜晚模式；棋盘大小会根据浏览器宽度和可用高度自适应。
- 游戏页顶部可以暂停计时、返回档案目录或重置当前关卡。
